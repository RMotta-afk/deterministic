The stronger vector follow-up used 5,988 model input tokens and an estimated US$ 0.00602782, versus 6,993 and US$ 0.00670275 for its graph counterpart. Its end-to-end runtime was 92,160 ms versus 24,241 ms. The follow-up strategy uses the fixture's explicit route→handler→contract ID grammar, so it is a sensitivity check, not a general vector-RAG benchmark.

`diagnostic-prompt-v1/` preserves an earlier paid pair: vector 1/12, graph 2/12. Its Analyst often had the correct evidence, but the Builder returned `UNKNOWN` after a conflicting handoff. It is excluded from scored comparisons, and its raw files are unchanged. `scored-one-shot/` contains all six successful run records and pair reports; `no-memory/` contains its control; `posthoc-strong-vector/` contains the later challenge. `shared_snapshot.json` is the shared preparation evidence. Raw run files retain per-step answers, retrieval IDs, context size, provider usage, latency, model responses, and memory records. `SHA256SUMS` covers these raw files.

`final-grounding-pair/` is an additional live pair run on **2026-11-14 UTC** (2026-11-13 in São Paulo) after adding an evidence-only grounding check; the folder retains the initial study date. Its CLI image manifest list was `sha256:d886b0fb3cad9206cada53f7008816ffa491559f9dc819d684d8a30d68977be4`. Vector answered 3/12, with 3 supported assertions, 0 unsupported assertions and 9 abstentions; graph answered 12/12, with 12 supported assertions, 0 unsupported assertions and no abstentions. The operational unsupported-assertion rate was 0/3 versus 0/12. Runtime provider cost was estimated at US$ 0.00516024 for vector and US$ 0.00668025 for graph, US$ 0.01184049 combined; shared preparation was cached. The judge never reads the hidden answer key; it verifies the asserted ID against the retrieved route statement or complete two-hop path. Adversarial unit tests confirm that a false ID and a correct ID without its necessary edge are marked unsupported. This narrow metric is **not** the PDF's proposed independent factual judge for free-form claims and does not demonstrate a lower hallucination rate for graph memory. The extra pair is not pooled with the three predeclared pairs.

**Conclusion supported here:** explicit two-hop graph traversal beat one-shot vector similarity on this tailored opaque fixture. A simple ID-aware follow-up in Qdrant tied the graph, and both arms recalled prior reviewer state equally. The pilot does not establish general graph superiority, a database-only speed effect, lower hallucination, or a durable advantage on real codebases.
